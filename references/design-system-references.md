# 디자인 시스템 참고 자료

외부 디자인 시스템은 정답이나 복제 대상이 아니라 정의 구조와 의사결정 방식을 비교하기 위한 자료로 사용한다.

## SEED Design

- 문서: <https://seed-design.io/>
- Foundation: <https://v3.seed-design.io/foundations/color>
- 컴포넌트 예시: <https://v3.seed-design.io/docs/components/field>
- AI 문서 연동: <https://v3.seed-design.io/ai-integration/docs-mcp>

참고할 관점:

- 목적과 Usage
- Anatomy와 Property
- Variant와 State
- 역할 기반 토큰과 실제 컴포넌트 참조 관계
- 플랫폼별 구현 상태와 차이
- 접근성, 반응형, 긴 콘텐츠와 모션

사용 규칙:

- 외부의 색상값, 명칭, 컴포넌트 API를 우리 서비스 결정으로 그대로 복제하지 않는다.
- 참고한 구조와 우리 서비스에서 채택한 결정을 구분한다.
- 페이지가 미완성이거나 버전별로 다르면 그 상태를 기록하고 다른 자료로 임의 보완하지 않는다.
