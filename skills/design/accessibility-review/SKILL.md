# 디자인 접근성 검토

문서상 요구와 실제 검증 결과를 구분한다. 준수 기준, 플랫폼과 측정 근거가 없으면 통과를 단정하지 않는다.

## 참조

- `../../../references/design-principles.md`
- 관련 Foundation, 컴포넌트, UI와 UX 문구
- 프로젝트가 확정한 접근성 기준

## 검토 범위

- 색상 대비와 색상 외 상태 단서
- 키보드 조작과 포커스 순서·복원
- 이름, 역할, 상태와 레이블
- 오류 위치, 연결, 요약과 복구
- 터치·클릭 영역과 확대·리플로우
- 애니메이션, 자동 갱신과 모션 감소
- 로딩, 비활성, 읽기 전용과 시간 제한

## 출력 형식

```markdown
# 접근성 검토 보고서

## 범위와 검증 방식
- 문서 검토 / 실제 렌더링 / 자동 검사 / 수동 검사
- 적용 기준:
- 검증하지 못한 범위:

## 발견 사항
### A11Y-{NN} [{Blocker|Major|Minor|Question}] {제목}
- 근거:
- 문제:
- 사용자 영향:
- 필요한 조치:
- 확인 방법:
- 관련 ID:

## 확인 완료
## 결정 필요
```

## 완료 기준

- 발견마다 실제 위치, 사용자 영향과 확인 방법이 있다.
- 자동 검사 통과를 전체 접근성 통과로 확대 해석하지 않는다.
- 문서에 없는 구현 결과를 추정하지 않는다.
